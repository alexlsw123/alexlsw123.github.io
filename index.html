LH 프로젝트에서 배운 것

신경망의 폭과 층 수, 입력 길이를 바꾼 실험은 대부분 차이가 없었습니다. 정확도를 올린 것은 시점 기준으로 다시 만든 학습 데이터와 2년치 기상 백필이었습니다.

배포 전에 잡은 문제. 네 건 모두 운영 경로를 재현하다 드러났습니다.

학습 데이터의 누설을 막았습니다

전 기간 캐시로 만든 학습 데이터에 정보 컷 이후 값이 섞여, 실험 성능이 운영보다 17% 좋게 나왔습니다.

시점 기준 학습 데이터
5개 중 5개
  • 날짜마다 정보 컷 패널을 다시 생성
  • 결측은 컷 이전 값으로만 채움
  • 학습 표본 31,377개, 4프로세스 40분
  • 네 기간을 운영 경로로 재현
  • 봄 기간 HGB 대비 열세에서 우세로

계량기 스파이크를 걸러냅니다

평소의 1,290배인 값 하나로 한 단지 R²가 −881까지 떨어졌습니다. 정규화를 중앙값과 IQR로 바꾸고 발행 전 상한을 뒀습니다.

  • 입력이 평소의 1,290배한 단지 · 2026-01-21 · 발행 제외
  • 정규화를 중앙값 · IQR로평균 · 표준편차 대신, ±8에서 자름
  • 1월 평균 R² 0.781−19.26에서 회복 · 신경망 기준

늦게 오는 검침도 예측합니다

지연 시간을 모델 입력으로 넣고 짧은 이력은 반복해 채워, 예측 비율을 74.1%에서 77.4%로 올렸습니다.

검침 지연 규칙
4개 중 4개 켜짐
  • 지연 시간을 입력으로0~12시간, 학습 때 무작위로
  • 짧은 이력 반복해 채우기2일 이상이면 14일로
  • 한 달 넘게 끊긴 단지 제외대부분 실측값도 없음
  • 보정 내역을 manifest에 기록지연 시간 · 채운 날 수

4비트 양자화 안전성 논문

NVIDIA가 배포한 NVFP4 체크포인트가 원본과 같은 유해 요청을 거절하는지, 영어와 한국어로 짝지은 요청 2,014개로 쟀습니다.

  • 채팅 템플릿만 바꿔도 한국어 거절률 34.6% → 62.7%
  • 유해 요청 5~10%가 거절에서 응답으로 바뀜 (재실행 잡음 0.5~2.2%)
  • 격차가 큰 모델에서 한국어 거절이 3~9%p 더 자주 뒤집힘
  • GPU 2장으로 나누기만 해도 한국어 유해 요청 최대 9% 뒤집힘
  • AAAI-27 Deployable AI 워크숍 제출 · 1저자

로컬 LLM 음성 비서를 만들었습니다

모델은 JSON 스키마로 강제한 계획 폼만 채우고, 도구 호출과 기본 답 문장은 코드가 맡도록 나눴습니다.

  • 계획 폼 작성qwen2.5:14b · 장소와 주제만 채움
  • 도구 호출은 코드가지도 이동 · 날씨 요약
  • 답은 문장 틀로한자가 섞이면 틀로 되돌림
